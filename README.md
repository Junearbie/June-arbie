# BSIT 1B Portfolio — One Image Version

This version uses **only one image**: the profile photo in the Home section. The Projects section uses text cards and does not need extra images.

## Files
- `index.html` — website structure, content, navigation, and mobile menu.
- `style.css` — website design and responsive layout.

## Change the profile image
In `index.html`, find the only `<img>` tag and replace the value of `src` with your own public image URL.

You can also download your photo into the project folder and use:
`src="images/profile.jpg"`

If you use a local image, create an `images` folder and put `profile.jpg` inside it.

## Customize before submitting
Change the sample name, about-me details, skills, projects, and email to your own information.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. The website URL will appear in the Pages settings.

The sample profile image is hosted by Unsplash, so it needs an internet connection to load.
